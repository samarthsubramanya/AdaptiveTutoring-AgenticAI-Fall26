# Verify a student solution

Use verify_symbolic_answer for supported symbolic tasks and verify_algebra_answer for the trusted equation bank. Only the checker assigns correctness. Invalid, unsupported, or inconclusive results are ungraded; explanation steps are not proved.

Never execute student text. Confirm ambiguous word-problem interpretations first. A correct final answer alone does not certify mastery.
